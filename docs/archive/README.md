# Contributor archive

This archive preserves historical guides and indexes selected research and engineering records. It is a reference collection, not the current workflow or release evidence. The project is in development, unreleased, and not in use.

Start with the current [README](../../README.md), [Getting Started](../GETTING-STARTED.md), and [Prime planning guide](../agents/itdd-in-prime-usage.md). **Collect source data first**; the [source inventory](SOURCE-INVENTORY.md) records what was found and what needs review before publication.

## Not included as public archive material

The source inventory identified raw `.idd` authority, audit, telemetry, execution-workspace, and event data; `.worktrees`; scratch output; and detailed reports based on private session metadata. These remain preserved in their existing locations and are not copied or linked as contributor-ready material. Review and sanitize individual sources before making them part of a public release or archive.

This index does not rewrite historical evidence or claim that every source has been reviewed. Historical acceptance applies only to the named candidate or milestone, not to the product as a whole.
