# Research records

Research records distinguish observed evidence, interpretation, and proposed architecture. External sources should be cited. Local observations must be labeled as local and must not be generalized into product guarantees.

The curated [contributor archive](../archive/README.md) indexes dated notes and engineering history. Read the [source inventory](../archive/SOURCE-INVENTORY.md) before using or sharing historical notes. Some source files contain machine-specific paths or depend on local evidence that is not included in the public repository.

These records are research context, not current operating policy. The current product path is the unreleased planning-first handoff described in the [Getting Started guide](../GETTING-STARTED.md).
