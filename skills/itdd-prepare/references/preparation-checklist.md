# ITDD Prepare checklist

- [ ] Six separate fresh sub-agent execution IDs and runtime provenance recorded.
- [ ] Discovery identifies immutable spec/ticket/intent and full baseline SHA.
- [ ] Grilling questions, answers, and blockers are preserved.
- [ ] Research cites sources and revisions; no unsupported requirements added.
- [ ] Decomposition names exact allowed paths and explicit exclusions.
- [ ] Contract has observable acceptance criteria.
- [ ] Positive tests have commands and expected results.
- [ ] Negative tests name the intended enforcement boundary, rejection, and no-state-change assertion.
- [ ] Artifacts/evidence have durable paths and identity bindings.
- [ ] Independent reviewer is fresh and separate from drafter.
- [ ] Human approval is explicit, identity-bound, and hashes the exact contract.
- [ ] No code implementation, BUILD, TEST, or VERIFY was run.
